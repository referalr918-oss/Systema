Завантаж конфіги для збірки APK (Capacitor / PWABuilder):
Команди для збірки справжнього .APK через Capacitor: 
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init "SistemaDnya" "ua.yusyp.sistemadnya" --web-dir=www
# Скопіюй цей HTML у www/index.html, потім:
npx cap add android && npx cap sync android
cd android && ./gradlew assembleDebug

Готовий файл з'явиться у android/app/build/outputs/apk/debug/app-debug.apk. Або завантаж цей файл на будь-який HTTPS-хостинг (наприклад, GitHub Pages) і згенеруй APK без коду через PWABuilder.com.
